# Krishna Neon Particle ✨
## Link:https://divine-particle-creation.vercel.app/

A cinematic Krishna particle animation built with React, TypeScript, and Canvas.

## Features

- Full-screen black background
- Krishna forms automatically from thousands of particles
- Gold and white glowing particles
- Subtle pink/purple energy effects
- Golden divine aura
- Detailed and recognizable Krishna artwork
- Smooth particle animation
- Automatic animation on page load
- Replay animation
- Responsive design for desktop and mobile
- Optimized particle rendering

## Technologies

- React
- TypeScript
- Vite
- HTML5 Canvas
- CSS
- JavaScript
