# Divine Particle Creation

I have an existing project called "Krishna". Do NOT rebuild the project from scratch. Modify the existing project.

GOAL:

Create a full-screen Krishna particle/neon drawing animation inspired by the reference video/screenshots I provided.

IMPORTANT:

I do NOT want a children's cartoon, simple diagram, basic SVG line drawing, or multiple Krishna images.

I want ONE detailed, artistic Krishna figure centered on a completely black screen.

ANIMATION:

1. When the website opens, immediately start the animation automatically.

2. Initially show only a few tiny, barely visible particles on the black screen.

3. Gradually generate thousands of particles/strokes that form the Krishna figure.

4. The Krishna should appear as if it is being created/drawn from glowing particles.

5. The animation should build progressively from small/random particles into the complete Krishna figure.

6. Do NOT simply fade an image in. The Krishna must visibly FORM from particles.

7. Use a dark black background throughout.

8. Use primarily GOLD/YELLOW particles and neon glow.

9. Add subtle WHITE highlights.

10. Add controlled PINK/PURPLE neon particles around appropriate areas, similar to the reference video.

11. Add a strong golden circular aura/glow around Krishna near the end.

12. At the end, the complete Krishna should remain visible with a beautiful neon glow.

13. Add subtle particle movement/twinkle after completion so the scene does not become completely static.

VISUAL STYLE:

- Detailed and elegant Krishna

- Divine / spiritual / cinematic

- Black background

- Gold neon

- White highlights

- Pink/purple energy accents

- Glowing particles

- Premium modern visual

- NOT cartoon

- NOT children's drawing

- NOT simple line art

- NOT a flat colored illustration

LAYOUT:

- Krishna centered vertically and horizontally.

- Krishna should occupy approximately 65–75% of the screen height.

- Maintain correct proportions.

- Make it responsive for desktop and mobile.

- On mobile, keep Krishna centered and fully visible.

TECHNICAL REQUIREMENT:

Use HTML/CSS/JavaScript and Canvas where appropriate.

The particle system should:

- Sample points from the Krishna target artwork/image.

- Animate particles from scattered/random positions toward their target positions.

- Use easing/interpolation for smooth movement.

- Add particle opacity, size, brightness and glow variation.

- Use Canvas compositing/glow effects where appropriate.

- Use requestAnimationFrame for smooth animation.

- Avoid excessive CPU/GPU usage.

- Handle window resizing correctly.

- Scale the particle artwork responsively.

ANIMATION TIMING:

- 0–1 sec: almost completely black, only a few particles.

- 1–4 sec: first parts of Krishna begin appearing.

- 4–8 sec: body, face, clothing and flute progressively form.

- 8–11 sec: detailed particles and aura become stronger.

- 11–13 sec: final neon/golden glow intensifies.

- After 13 sec: complete Krishna remains glowing with subtle particle movement.

CONTROLS:

Keep the UI minimal.

Do NOT put large text over Krishna.

Optionally add a small "Replay" button near the bottom.

Replay should restart the particle animation.

EXISTING PROJECT:

Inspect the existing files before changing anything.

Preserve the current project structure wherever possible.

Do not unnecessarily delete existing functionality.

IMPORTANT FILES:

- index.html

- css/style.css

- js/app.js

- js/drawing-engine.js

- assets/krishna/

Use the existing Krishna target artwork if it is suitable. If the existing artwork is a simple diagram/cartoon, replace it with a more detailed Krishna target suitable for a particle effect.

FINAL RESULT:

When I open index.html, I should immediately see a black screen and then ONE beautiful detailed Krishna gradually forming from gold/white/pink glowing particles, exactly like a cinematic neon particle artwork.
